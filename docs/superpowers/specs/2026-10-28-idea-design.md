# IDEA 교육과정 탐색 도우미
대학생 선생님이 공식 교육과정을 스스로 검토하고 수업을 설계하도록 돕는 I 단계 도구.
사용자 명세를 구현 기준으로 삼는다. 아이보리/민트/초록, 반응형 탐색 화면, 원문 정보와 해석 제안을 분리한다.
## 구현 결정
Vinext/React, D1 분석 및 검수 데이터, R2 PDF. API 비용 없는 용어 확장 검색을 기본 제공하며 생성형 AI 연결 상태를 명확히 표시한다. 공식 원문은 코드+고시 버전+PDF쪽수로 식별한다. 확인되지 않은 필드는 null. 최초 고시와 후속 개정 이력은 분리하고 최신이라고 추정하지 않는다.
검증된 기본 자료는 배포 데이터로 유지한다. 업로드 자료와 검수 결과는 사용자별 작업 공간에 저장하여 다른 사용자의 공식 검색 자료를 오염시키지 않는다. 개인 검수 결과를 공용 검증 완료 자료처럼 표시하지 않는다.
초등 기본, 중고등 필터 지원. 미수집 범위는 미등록. 학년군은 문서의 공식 단위이며 개별 학년 배정으로 오해하지 않게 한다.
## 비교한 방식
정적 앱은 저렴하지만 서버 저장과 문서 관리에 제약. 서버 앱은 지속 저장과 자료 검수가 가능해 선택. 외부 유료 AI 전용 검색은 비용과 원문 생성 위험 때문에 기본 검색에 필수로 두지 않는다.
## 주요 흐름
검색 → 필터 → 원문·해설·내용 체계 → PDF 쪽수 확인 → 기준 비교·융합 구상 → 분석 저장·복사·인쇄 PDF·문서 내보내기.
## 검증
검색 예시 세 가지, 무결과, 중고등 미등록, 사용자 분리, 미검수 제외, PDF쪽수, 새로고침 저장 복원, 모바일 화면을 확인한다.
