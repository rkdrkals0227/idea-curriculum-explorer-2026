# IDEA 운영 안내

## 현재 제공 범위
- 초등 3~4/5~6학년군 39개 성취기준(수학10, 과학12, 사회11, 도덕6).
- 공식 원본 PDF 5개, 내장 페이지 뷰어, 고시별 출처와 적용 일정.
- 용어 확장 기본 검색. 생성형 AI API는 연결하지 않았으며 비용이 발생하지 않음.
- 중고등과 초1~2 성취기준, 출판사별 교과서 단원은 미등록. 문서에 명시되지 않았다고 단정하지 않음.

## 저장과 검수
Sites 로그인 ID로 사용자별 D1 기록과 R2 PDF가 분리된다. 업로드 문서의 실제 페이지 수는 서버 pdf-lib로 확인한다. 검수 전에는 검색 제외. 검수 후에도 개인 검수로 표시되고 명시적으로 포함해야 검색된다. 공용 공식 자료는 `data/curriculum.json`과 원본 PDF를 검증한 뒤 재배포하여 갱신한다.
분석에는 선정 당시 성취기준·출처 사본을 저장한다. 문서 버전이 바뀌어도 이미 저장한 분석 근거는 바뀌지 않는다. 다중 탭 저장 충돌을 감지한다. 작성 중인 임시 초안은 현재 브라우저 탭에 보관되며 서버 저장과 다르다.

## 자료 갱신
1. 교육부, NCIC, 국가교육위원회의 새 고시/정정 공지 확인.
2. 새로운 파일을 별도 버전으로 등록하고 SHA-256 보존.
3. 코드·문장·학교급·학년군·영역·고시·PDF/인쇄 쪽수를 대조.
4. 내용 체계 범위를 명시하고 불명확한 필드는 null 유지.
5. 기본 검증 코퍼스 업데이트 시 `python scripts/verify-curriculum.py` 실행.

## AI 확장
공식 자료 저장소와 검색 함수는 UI에서 분리되어 있다. `lib/search-provider.ts`는 AI가 기존 등록 ID를 추천하고 해석만 추가하도록 하는 경계이다. 생성된 코드·원문을 수용하지 않는다. 향후 서버 전용 API를 추가해 검색 후보 ID와 원문을 전달하고, 응답을 이 경계로 검증한다. API 키는 Sites의 서버 환경변수로 설정하며 브라우저 코드에 포함하지 않는다. 설정이 없거나 API가 실패하면 `searchStandards`로 폴백한다. 현재 UI는 이 기본 모드임을 명시한다.

## 확인 명령
- `node --experimental-strip-types --test tests/*.test.ts`
- `python scripts/verify-curriculum.py`
- `node node_modules/typescript/bin/tsc --noEmit`
- Sites build helper 실행 후 `node tests/integration.mjs` (임시 D1/R2, 실제 서비스 데이터 변경 없음)

## 내보내기
분석 내용을 복사하거나 UTF-8 텍스트로 내려받을 수 있다. ‘PDF 저장’은 브라우저 인쇄 대화상자에서 PDF 저장을 선택하는 방식이다.
